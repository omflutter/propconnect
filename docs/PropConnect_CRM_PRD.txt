1. Executive Summary
The real estate industry operates in a fast-paced, relationship-driven environment where information asymmetry between agents can cost deals and damage client trust. Today, a typical real estate firm employing 10 to 20 or more agents faces a critical operational gap: each agent manages their own leads, properties, and clients in isolation. This results in duplicated effort, missed co-brokerage opportunities, and no single source of truth for the firm's property portfolio.

PropConnect CRM is designed to solve this problem. It is a purpose-built Customer Relationship Management platform for real estate agencies that unifies property listings, lead management, inter-agent communication, and transaction tracking into one cohesive system. PropConnect operates across a mobile app and a web-based admin panel, with role-based access ensuring owners retain full control while agents efficiently manage their day-to-day workflows.





Key Platform Highlights



Unified property portfolio — all agents see the firm's listings in one place



Public / Private property visibility — agencies control what is shared externally



Cross-agency deal collaboration — buyer agents and seller agents can transact seamlessly



Transaction milestone tracking — token, agreement, and registry stages all tracked



Automated client follow-up — scheduled reminders and messaging built in



Role-based access — Owner, Manager, Agent, and Read-Only roles



Mobile app + Admin panel — full coverage across devices

4.2 Lead Management Module
Leads are potential buyers or tenants who have expressed interest in a property. Effective lead management is the primary driver of revenue in any real estate operation.

4.2.1 Lead Data Fields
Lead Name, Phone Number, Email Address
Lead Source — Walk-in, WhatsApp, Portal (99acres, MagicBricks, Housing), Referral, Cold Call, Website, Social Media
Lead Type — Buyer / Tenant / Investor
Budget Range — minimum and maximum
Preferred Property Type and Location
BHK Requirement — 1BHK / 2BHK / 3BHK / 4BHK+ / Commercial
Lead Status — New / Contacted / Site Visit Scheduled / Site Visit Done / Negotiation / Token Paid / Deal Closed / Cold / Lost
Assigned Agent — which agent is managing this lead
Priority — Hot / Warm / Cold
Follow-Up Date — next scheduled follow-up
Communication History — all calls, messages, meetings logged

4.2.2 Lead Pipeline View
The lead module includes a Kanban-style pipeline view where leads can be dragged between stages. Agents can also toggle to a list view or a calendar view to see follow-ups organized by date.

4.2.3 Lead Assignment Rules
Owners and Managers can manually assign leads to any agent
System supports round-robin auto-assignment if enabled
Leads can be re-assigned with a reason and audit trail
Unassigned leads older than a configurable threshold trigger an alert to the Manager

4.3 Client Communication & Follow-Up Module
Communication is the lifeblood of real estate sales. PropConnect centralizes all client interactions, ensuring nothing falls through the cracks and the firm (not just individual agents) retains institutional knowledge about every client relationship.

4.3.1 Messaging Features
In-app messaging with clients (WhatsApp-style chat interface)
Pre-built message templates for common scenarios (property sharing, follow-up reminders, congratulation messages for closed deals)
Bulk messaging — send a property card to multiple leads at once
Message scheduling — schedule a follow-up message for a future date and time
Property sharing — share a formatted property summary card directly from the property module
Read receipts and message status tracking

4.3.2 Follow-Up Management
Every lead must have a follow-up date set — agents are alerted if a lead has no follow-up scheduled
Follow-up reminders via push notification, SMS, and email
Follow-up outcomes are logged (Contacted / No Answer / Interested / Not Interested / Site Visit Scheduled)
Overdue follow-ups are highlighted in the dashboard for managers
Follow-up frequency analytics — track which agents are most consistent

4.3.3 Activity Timeline
Every lead and property has a complete, chronological activity timeline showing all calls, messages, site visits, price negotiations, and document submissions. This creates an institutional memory that persists even if the agent who managed the relationship leaves the firm.

4.5 Inter-Agency Collaboration Module
Real estate deals frequently involve two agencies — one representing the seller and one the buyer. PropConnect supports this with structured co-brokerage features.

4.5.1 How Cross-Agency Deals Work
Agency A lists a property as Public
Agency B's agent finds the property while searching public listings
Agency B's agent sends a co-brokerage request on the property
Agency A's manager approves or declines the request
If approved, both agencies can see the deal progress on their respective dashboards
Commission split is agreed upon and recorded in the system
Each agency's view of the deal is filtered — neither sees the other's client details

4.5.2 Privacy in Cross-Agency Deals
Agency A cannot see Agency B's buyer contact details
Agency B cannot see Agency A's owner negotiable price or internal notes
Deal milestones and documents are shared only as agreed
All cross-agency communication goes through the in-platform messaging system

4.6 Owner & Agent Directory

4.6.1 Property Owner Profile

4.6.2 Agent Performance Profile
Agent contact details, joining date, assigned territory
Active leads count, converted leads, conversion rate
Active properties listed
Revenue generated (commissions closed)
Follow-up compliance score
Monthly and quarterly performance reports

6.2 Mobile App (iOS & Android)
The mobile app is designed for field agents who need full CRM access while on site visits, at client meetings, or away from their desks.

6.2.1 Mobile App Key Screens
Dashboard — daily summary of tasks, follow-ups due, pipeline overview
Property Search — search and filter the full agency property portfolio with photos
Property Detail — full property card with owner info, documents, transaction status
Lead Manager — list, pipeline, and calendar views of leads
Follow-Up Tracker — today's follow-ups, overdue alerts, quick call/message actions
Client Chat — in-app messaging with clients, property sharing
Site Visit Logger — log visits with geo-location stamp, photos, and notes
Quick Add — rapid property or lead entry from the field
Notifications Center — all alerts, reminders, and approvals

6.2.2 Offline Capability
The mobile app supports offline mode for core functions. Agents can view cached property data and add notes when connectivity is poor. Data syncs automatically when connection is restored.

7. Additional Features & Enhancements
7.1 Smart Dashboard & Analytics
Pipeline value overview — total value of active deals by stage
Agent leaderboard — ranked by leads converted, revenue, and follow-up compliance
Property velocity chart — how long properties stay in different stages before closing
Lead source ROI — which sources (portals, referrals, walk-ins) generate the best leads
Monthly and quarterly revenue forecasting based on pipeline data
Heat map of property locations — visual cluster analysis for market insights

7.2 Automated Reminders & Alerts
Follow-up due today / overdue — push notification on mobile + email digest
Registry date approaching — alert 7 days, 3 days, and 1 day before
Token expiry — alert if agreement not progressed within configured days after token
Lead inactivity alert — flag leads with no activity for X days
Property listing expiry — alert if property is still active after 90/180 days
Birthday / anniversary reminders for clients — relationship management feature

7.3 Document Management
Centralized storage for all deal-related documents — sale agreements, token receipts, ID proofs, NOCs, title documents
Per-property and per-lead document folders
Version control — track document revisions
Access control — documents can be restricted to specific roles
E-signature integration (optional phase 2) — for agreement signing
Document expiry alerts — for time-sensitive legal documents

7.4 Property Matching Engine
PropConnect includes an intelligent matching system that automatically suggests relevant properties to leads based on their requirements.
When a new lead is added with their requirements (budget, location, BHK), the system automatically suggests matching properties
Agents receive a notification: '3 properties match your new lead — view suggestions'
Agents can send a formatted property brochure directly to the lead with one tap
System learns from closed deals to improve match quality over time

7.5 Commission & Revenue Tracking
Define commission structures (percentage-based or flat fee) per deal type
Track expected and received commission for every closed deal
Agent-wise commission reports for payroll and incentive calculations
Commission split tracking for co-brokerage deals
Tax document support — generate commission certificates for agents

7.6 Property Comparison Tool
Agents can compare up to 3 properties side-by-side for a client
Comparison covers area, price, location, amenities, transaction status
Comparison report can be shared with the client as a PDF or via WhatsApp

7.7 Site Visit Management
Schedule site visits from within the lead or property record
Agents receive mobile reminders before scheduled visits
Visit log includes geo-location stamp, time, duration, photos taken during visit
Post-visit feedback form — capture client reactions and next steps immediately after the visit
Visit history visible to managers for coaching and quality assurance

8. Security & Data Privacy
8.1 Authentication & Authorization
JWT-based authentication with short-lived access tokens and long-lived refresh tokens
Role-based access control enforced at API level — not just UI level
Two-factor authentication (OTP via SMS) for Owner and Manager logins
Session management — active sessions visible, remote logout available
IP whitelisting option for admin panel access

8.2 Data Security
All data encrypted in transit (TLS 1.3) and at rest (AES-256)
Owner and client PII (phone numbers, financial data) masked in certain role views
Document storage with access-controlled signed URLs — documents are not publicly accessible
Database backups every 24 hours with 30-day retention
Penetration testing before go-live and quarterly thereafter

8.3 Audit & Compliance
Complete audit log — every create, update, delete action logged with user, timestamp, and IP
Data retention policy configurable by owner (e.g., leads retained for 3 years)
Data export — owners can export all their data in CSV/Excel format at any time
GDPR/DPDP compliant data handling — client consent captured and stored
Right to erasure — client data can be permanently deleted on request

12. Glossary




Term


Definition



Token / Booking Amount


An advance payment made by the buyer to the seller to reserve the property, typically 1-2% of property value



Agreement to Sell


A legal document signed by both parties committing to the sale transaction at a defined price and timeline



Registry


The formal registration of the property sale deed at the Sub-Registrar Office, making the transfer legally valid



CRM


Customer Relationship Management — a system for managing all interactions with clients and leads



Co-brokerage


A deal where two agents from different agencies collaborate — one representing the buyer, one the seller



Lead


A potential buyer or tenant who has shown interest in purchasing or renting a property



Pipeline


The collection of deals at various stages of progress, representing potential future revenue



KYC


Know Your Customer — the process of verifying the identity of clients and property owners



RBAC


Role-Based Access Control — a method of restricting system access based on the user's role



BHK


Bedroom, Hall, Kitchen — used to describe apartment configurations (e.g., 2BHK = 2 bedrooms)



JWT


JSON Web Token — a secure token format used for user authentication



MVP


Minimum Viable Product — the smallest version of a product that delivers core value
